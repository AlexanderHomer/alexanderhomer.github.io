# Rhode Island Hospital - OR Guide

## Overview
### Workflow
* Get in early and help set-up room
* Attending performs both pre-induction and pre-procedure timeout
* After OR, complete ***brief op note*** ASAP, ideally before patient leaves room
* OP note, of course. Many attendings like this within 24h
* ***To complete discharge, must do:***
1. Med rec/orders
2. Discharge instructions
3. Sign the AVS
* ***If admitting:***
1. Inpatient orders (either ENT general admission or ENT tonsillectomy/adeoidectomy admission)
2. Text out into the WhatsApp
3. Fill out handoff
4. Eventually, postop check

### Useful info/where to find things
* Hasbro ORs are denoted by color (green, blue, etc) and are next to the Main ORs
* ASC ORs are in the first floor of COOP (basically right below clinic)
* Hasbro supplies can be found in the big supply closet across from blue room. Otherwise, the main core is adjcent to OR 12+
* Yellow honeycomb foam can be found outside this room ^
* Trachs can be found in central supply in the basement of Main Building

## Tarro
### T+A
* Does ***adenoid first*** at setting of 35
* Uses ***adenoid curette***
* Uses ***2x*** red rubber catheters and clamps
* No head wrap
* Tonsils at setting of 20 across the board for bovie and suction electrocautery
* Passes NGT into stomach after

### DL biopsy
* Uses ***2x EtOH packets*** (unopened) as a mouth guard

### Myringoplasty
* Freshens edgew with pick (not perforation per se)
* Patches with gelfoam

## Groblewski
* Will want to run the ***UO patients*** with you
### T+A
* Tonsils first
* Red rubber cath, does ***NOT*** clamp. Ties the catheter with ends out like a handlebar mustache
* No head wrap

## Gibson
### T+A
* Does tonsils first
* Uses ***suction cautery*** for tonsils
* 1x red rubber catheter and clamps
* ***White sheet*** over face
* Passes red rubber to stomach

### DLB
* Does ***NOT*** use mouthguard
* Have ***ventilating bronch*** set up no matter what
* Holds camera with pistol grip

### TGDC
* Like Koenigs, will dissect to and confirm ***thyroid cartilage*** prior to skeletonizing the hyoid bone.
* Places ***blue rubber band drain***
* Approximate strap muscles with 4-0 Vicryl, Platysma/dermal with 4-0, skin with a running locked 6-0 fast (5-0 if none available)
* Steris, fluffs, flexinet
* Pull blue rubber band drain POD1 if output ok. ***Make one cut in the loop and pull it out.*** Place steris to exit sites.

## Koenigs 
* Will want to run the ***UO patients*** with you
### DLB
* If with Dr. Satterthwaite (or some other attendings), will have you mask ventilate
* Does use mouthguard if dentulous
* Holds camera overhand

### TGDC
* Make sure to find ***thyroid cartilage*** prior to removing hyoid bone (will often do this after initial isolation of cyst)
